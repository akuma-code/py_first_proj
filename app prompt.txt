название программы: netCalculator
переменные: тип сетки - skf, simple, hooks, 
данные, который вводит пользователь: ширина -  sourceW, высота - sourceH, тип сетки.

основной интерфейс: 
при помощи tkinter,
верхний ряд: поля sourceW, sourceH, радио-переключатель типа сетки, кнопки "посчитать", "удалить все"
нижний ряд: поле для вывода результата в виде карточек.
карточка результата: получившиеся размеры, размеры источника, переключатель смены типа сетки, кнопка удалить карточку,


калькуляция результата: в зависимости от типа сетки высчитать ее размер. Для типа skf: ширина: - 45, высота: -47; simple: ширина: +30, высота: +40, hooks: ширина: +40, высота: +30.
